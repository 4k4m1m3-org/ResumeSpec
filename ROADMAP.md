# Roadmap

ResumeSpec v1.0.0 closes the first stable core of the standard.

## Completed For v1.0.0

### Phase 1 - Foundation

Status: Completed

- Repository structure.
- Vision and principles.
- Governance and contribution documents.
- Licensing model.
- RFC structure.

### Phase 2 - Specification

Status: Completed

- Core model.
- Document structure.
- Section semantics.
- Canonical JSON Schema.
- Reference examples.
- Validation tests.

### Phase 3 - Reference Implementation

Status: Completed for v1 scope

- Python parser.
- Python validator.
- CLI validation and parsing.
- Editable package installation.
- CI test workflow.

## Post-v1

The following work is intentionally outside ResumeSpec v1.0.0:

- Advanced documentation website.
- Multi-language SDKs.
- PDF generators.
- Portfolio generators.
- ATS exporters.
- ATS scoring.
- AI features.
- Platform integrations.
- XSD.
- Complete extension registry.
- Product workflows.

Post-v1 work should not change the v1 core contract unless it goes through an explicit versioned specification process.
