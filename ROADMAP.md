# Roadmap

## Overview

This document describes the planned evolution of ResumeSpec.

The roadmap represents the project's current direction and priorities. It is intended to provide visibility into upcoming goals, while allowing flexibility as the project grows and receives feedback from contributors and users.

ResumeSpec is being developed incrementally, starting from a clear specification foundation and evolving toward a complete ecosystem of tools, implementations, and integrations.

---

# Project Vision

The long-term vision of ResumeSpec is to establish an open, structured, and interoperable standard for representing professional information.

ResumeSpec aims to enable:

- Portable professional profiles.
- Machine-readable resumes.
- Better interoperability between platforms.
- Automated validation and processing.
- Improved privacy and ownership of professional data.
- Reliable integrations between tools and services.

# Phase 2 - Specification Development

Status: In Progress

Goal:

Create a stable and well-defined ResumeSpec specification.

Objectives:

- Define the core resume structure.
- Establish required and optional fields.
- Define data types and validation rules.
- Document compatibility expectations.
- Create examples and reference documents.

Planned work:

- Complete specification documentation.
- Define versioning strategy.
- Create the first stable specification release.
- Publish JSON Schema definitions.
