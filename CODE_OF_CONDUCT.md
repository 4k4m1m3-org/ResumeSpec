# Code of Conduct

## Our Commitment

The ResumeSpec community is committed to providing a welcoming, respectful, and inclusive environment for everyone who participates in the project.

We value collaboration, open discussion, and constructive feedback. We expect all contributors, maintainers, reviewers, and community members to interact professionally and respectfully.

This Code of Conduct applies to all project spaces, including:

- Source code repositories.
- Issues and discussions.
- Pull requests.
- Documentation contributions.
- Community channels related to ResumeSpec.

---

# Expected Behavior

Community members are expected to:

- Be respectful and professional in all interactions.
- Provide constructive feedback focused on improving the project.
- Respect different opinions, experiences, and approaches.
- Accept constructive criticism gracefully.
- Collaborate with others toward common goals.
- Use inclusive and welcoming language.
- Give credit to others for their contributions.
- Follow the project's technical and community guidelines.

---

# Unacceptable Behavior

The following behaviors are considered unacceptable:

- Harassment, discrimination, or personal attacks.
- Offensive comments or inappropriate language.
- Threats, intimidation, or hostile behavior.
- Deliberately disrupting discussions or project activities.
- Publishing private information without permission.
- Misrepresenting others' contributions.
- Trolling, provoking conflicts, or engaging in bad-faith discussions.
- Any behavior that creates an unsafe or hostile environment.

---

# Technical Discussions

ResumeSpec is a technical project focused on developing an open specification.

Disagreements about:

- Architecture decisions.
- Specification design.
- Implementation approaches.
- Technical trade-offs.

are expected and encouraged when handled respectfully.

Contributors should focus on:

- Technical arguments.
- Evidence.
- Project goals.
- Long-term maintainability.

Criticism should address ideas and implementations, not individuals.

---

# RFC Discussions

RFC discussions are an important part of the ResumeSpec evolution process.

Participants should:

- Review proposals objectively.
- Explain concerns clearly.
- Provide alternatives when possible.
- Avoid dismissive or personal responses.

The goal of RFC discussions is to improve the specification through collaboration.

---

# Enforcement

Project maintainers are responsible for maintaining a respectful environment.

Actions that may be taken in response to unacceptable behavior include:

- Requesting changes in communication style.
- Removing inappropriate comments or content.
- Closing discussions that become unproductive.
- Restricting participation in project spaces.
- Temporarily or permanently removing access for repeated violations.

Enforcement decisions will consider:

- The severity of the behavior.
- The context of the situation.
- Previous incidents.
- The impact on the community.

---

# Reporting Issues

If you experience or witness unacceptable behavior, please report it through the appropriate project communication channels.

When reporting an issue, include:

- A description of the situation.
- Relevant links or references.
- Any additional context that may help understand the incident.

Reports will be handled as confidentially as possible.

---

# Scope

This Code of Conduct applies to all individuals participating in ResumeSpec activities, including:

- Contributors.
- Maintainers.
- Reviewers.
- Users.
- Community members.

By participating in the project, you agree to follow this Code of Conduct.
