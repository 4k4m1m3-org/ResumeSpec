# XML Examples

XML is supported by the Python reference implementation as an experimental format.

## File

- [`examples/xml/minimal.xml`](https://github.com/4k4m1m3-org/ResumeSpec/blob/v1.0.0/examples/xml/minimal.xml)

## Status

XML is parsed with `defusedxml`. It does not have an independent normative schema in v1.0.0.
