# Examples

ResumeSpec ships reference examples that act as executable documentation.

## Available Examples

- [JSON](/examples/json)
- [YAML](/examples/yaml)
- [XML](/examples/xml)

## What They Show

- `minimal`: smallest conforming profile
- `developer`: realistic complete profile
- `edge-extension`: valid `x-*` extensibility
- `invalid-unknown-field`: intentionally invalid document
