# Introduction

ResumeSpec defines professional information and its structure. It does not define visual CV design, PDF generation, portfolio generation, ATS scoring, AI behavior, exporters, or product workflows.

The standard exists because a professional identity should not be trapped inside a single vendor, layout, or representation.

## The Principle

**One professional identity. Unlimited representations.**

## What ResumeSpec Is

- an open standard
- a machine-readable contract
- a portable professional identity model
- a foundation for parsers, validators, and future tools

## What ResumeSpec Is Not

- a resume template
- a design system
- a portfolio builder
- a PDF generator
- an ATS scoring engine

Those are downstream implementations.
