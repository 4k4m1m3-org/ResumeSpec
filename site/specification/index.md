# Specification

ResumeSpec v1.0.0 is the first stable release of the standard.

The normative authority order is:

1. `spec/` for semantics
2. `schemas/json/resumespec.schema.json` for the machine-readable contract
3. `examples/` for conforming and invalid documents
4. `tests/` for conformance
5. parser / validator / CLI for the reference implementation

## Current Release

The published stable release is [v1.0.0](https://github.com/4k4m1m3-org/ResumeSpec/releases/tag/v1.0.0).
