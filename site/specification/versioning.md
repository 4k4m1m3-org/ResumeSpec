# Versioning

ResumeSpec uses semantic versioning and currently publishes **v1.0.0**.

## Current Identity Fields

- `metadata.resumespecVersion`: `1.0.0`
- `metadata.schemaVersion`: `1.0.0`

## Meaning

- `resumespecVersion` identifies the specification version.
- `schemaVersion` identifies the JSON Schema contract version.
- `profileVersion` may describe an individual profile version.

## Stability

v1.0.0 is the first stable release. Future changes must preserve the published contract or publish a new versioned contract.
