# Roadmap

The v1.0.0 release is the stable core. Everything below is either available now or intentionally planned for later.

## Available Now

- v1.0.0 specification
- JSON Schema
- JSON, YAML, and XML examples
- Python parser, validator, and CLI
- Automated tests

## Planned

- documentation website expansion
- multi-language SDKs
- PDF generators
- portfolio generators
- ATS exporters and scoring
- AI tooling
- integrations
- XSD
- extension registry
- product workflows

## Status Note

The documentation website you are reading is part of the current implementation effort. The long-term roadmap still includes a broader documentation ecosystem beyond this initial site.
